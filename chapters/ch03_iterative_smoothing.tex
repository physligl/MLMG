\chapter{线性系统求解与迭代方法}
\label{ch:linear-solvers}

\chapref{ch:discretization}和\chapref{ch:amr-discretization}已经把连续 PDE 变成离散线性系统
\begin{equation}
A\bm u=\bm b.
\end{equation}
从这里开始，本书第一次把问题完整放在线性代数层处理：给定 $A$ 与 $\bm b$，怎样选择求解方法，怎样衡量误差与残差，怎样判断收敛速度，以及怎样利用矩阵结构减少计算代价。

本章首先建立求解器的总体地图，然后分别讲直接法、平稳迭代、Krylov 子空间方法、共轭梯度法（Conjugate Gradient, CG）、广义最小残差法（Generalized Minimal Residual, GMRES）以及预条件。柔性广义最小残差法（Flexible GMRES, FGMRES）只建立足够支撑后续多重网格预条件的最低模型。与 multigrid 特有的“平滑”相关的 Jacobi 网格依赖、高频衰减和加权 Jacobi 分析移到\chapref{ch:two-grid}开头，以保持本章的任务集中在\textbf{一般线性系统求解}。

\begin{keybox}
\textbf{本章主线：}
\[
\boxed{
A\bm u=\bm b
\rightarrow
\text{直接法 / 迭代法}
\rightarrow
\text{误差与残差}
\rightarrow
\text{平稳迭代}
\rightarrow
\text{Krylov 子空间}
\rightarrow
\text{CG / GMRES}
\rightarrow
\text{预条件}
}
\]
读完本章以后，读者应能根据矩阵结构选择基本求解路线，并能解释为什么“求解器”和“预条件器”是两个不同角色。
\end{keybox}

\section{线性系统的求解路线}
\label{sec:linear-solver-map}

面对
\begin{equation}
A\bm u=\bm b,
\end{equation}
首先需要区分两类基本策略。

\textbf{直接法}通过矩阵分解和有限次代数运算得到解。典型代表是 LU 分解与 Cholesky 分解。

\textbf{迭代法}从初始猜测 $\bm u^{(0)}$ 出发，构造一系列近似
\begin{equation}
\bm u^{(0)},\bm u^{(1)},\bm u^{(2)},\ldots,
\end{equation}
使其逐步逼近真解。平稳迭代、Krylov 子空间方法和 multigrid 都属于这一大类，但它们利用的信息不同。

平稳迭代重复固定的更新规则；Krylov 方法利用不断扩展的子空间和历史搜索信息；multigrid 则利用误差在不同空间尺度上的结构。预条件不应看成与这些方法平行的“第五类求解器”，它是一种把原系统变得更适合迭代的变换机制。

\section{直接法：分解、填充与适用范围}

对一般非奇异矩阵，高斯消元通常伴随行置换，可写成
\begin{equation}
PA=LU,
\end{equation}
其中 $P$ 是置换矩阵，$L$ 为下三角矩阵，$U$ 为上三角矩阵。随后通过前代和回代完成求解。

若 $A$ 对称正定（symmetric positive definite, SPD），则可以使用 Cholesky 分解
\begin{equation}
A=LL^T.
\end{equation}
它利用了对称性与正定性，通常比通用 LU 更节省存储与计算。

直接法的关键工程问题不是“原矩阵是否稀疏”，而是消元以后因子是否仍然稀疏。稀疏矩阵分解时，原先为零的位置可能产生新的非零元，这称为\textbf{填充（fill-in）}。因此一个七点 stencil 产生的稀疏矩阵并不意味着它的 $L/U$ 因子也只有七点结构。

这解释了直接法的典型定位：中小规模系统、最粗 multigrid 层、需要高鲁棒性的基准计算，以及矩阵固定而右端多次变化、因子可以复用的场景。对于超大规模三维 PDE，填充带来的内存和分解成本往往使迭代法更有吸引力。

\section{迭代法的共同语言：误差、残差与条件数}

设真解为 $\bm u^\star$，当前近似为 $\bm u^{(k)}$。定义误差
\begin{equation}
\bm e^{(k)}
=
\bm u^\star-\bm u^{(k)}
\label{eq:linear-solvers-error}
\end{equation}
和残差
\begin{equation}
\bm r^{(k)}
=
\bm b-A\bm u^{(k)}.
\label{eq:linear-solvers-residual}
\end{equation}
因为 $A\bm u^\star=\bm b$，
\begin{equation}
\boxed{
\bm r^{(k)}=A\bm e^{(k)}.
}
\label{eq:linear-solvers-residual-error}
\end{equation}

因此“残差很小”和“误差很小”不是同一个命题。若 $A$ 可逆，
\begin{equation}
\bm e=A^{-1}\bm r.
\end{equation}
对选定的相容向量范数及其诱导矩阵范数，
\begin{equation}
\|\bm e\|
\le
\|A^{-1}\|\,\|\bm r\|.
\end{equation}
定义条件数
\begin{equation}
\kappa(A)
=
\|A\|\,\|A^{-1}\|.
\label{eq:linear-solvers-condition-number}
\end{equation}
若 $\bm b=A\bm u^\star\neq0$，则
\begin{equation}
\frac{\|\bm e\|}{\|\bm u^\star\|}
\le
\kappa(A)
\frac{\|\bm r\|}{\|\bm b\|}.
\label{eq:linear-solvers-relative-bound}
\end{equation}

条件数大的系统会放大残差与解误差之间的不确定性。因此停止准则不能只写“残差变小了”，而要明确使用什么范数、相对哪个量归一化、是否达到离散误差允许的精度。

常见相对残差准则是
\begin{equation}
\frac{\|\bm r^{(k)}\|_2}{\|\bm b\|_2}
\le
\tau.
\label{eq:linear-solvers-relative-residual-stop}
\end{equation}
若 $\bm b=0$ 或需要更稳健的尺度，还可以使用初始残差
\begin{equation}
\frac{\|\bm r^{(k)}\|_2}{\|\bm r^{(0)}\|_2}
\le
\tau.
\end{equation}

纯 Neumann 问题存在零空间时，整个空间上的 $A^{-1}$ 不存在；此时必须先处理兼容条件和 gauge，再在可逆子空间上讨论误差、残差和条件数。

\begin{keybox}
\[
\boxed{
\text{误差：离真解多远}
\qquad
\text{残差：方程满足得多好}
\qquad
\text{条件数：二者之间可能放大多少}
}
\]
\end{keybox}

\section{平稳迭代}

\subsection{统一形式与误差传播}

大量经典迭代可以写成
\begin{equation}
\bm u^{(k+1)}
=
\bm u^{(k)}
+
M^{-1}
\left(
\bm b-A\bm u^{(k)}
\right),
\label{eq:linear-solvers-stationary}
\end{equation}
其中 $M$ 在各轮迭代中保持不变，并且比完整 $A$ 更容易求逆或求解。

用真解减去两边，
\begin{equation}
\bm e^{(k+1)}
=
\left(
I-M^{-1}A
\right)\bm e^{(k)}.
\end{equation}
定义误差传播矩阵
\begin{equation}
S
=
I-M^{-1}A,
\label{eq:linear-solvers-error-propagation}
\end{equation}
则
\begin{equation}
\bm e^{(k)}=S^k\bm e^{(0)}.
\end{equation}

有限维线性平稳迭代从任意初始误差出发收敛的充要条件是
\begin{equation}
\boxed{
\rho(S)<1,
}
\label{eq:linear-solvers-stationary-convergence}
\end{equation}
其中 $\rho(S)$ 为谱半径。

若 $S$ 非正规（non-normal），某些范数下可能出现短暂误差增长，因此 $\rho(S)<1$ 不等于“每一轮误差范数都严格缩小”。它控制的是最终的渐近行为。

\subsection{Jacobi 与 Gauss--Seidel}

写
\begin{equation}
A=D+L+U,
\end{equation}
其中 $D$ 为对角部分，$L$、$U$ 分别为严格下三角和严格上三角部分。

Jacobi 取
\begin{equation}
M=D,
\end{equation}
因此
\begin{equation}
\bm u^{(k+1)}
=
\bm u^{(k)}
+
D^{-1}
\left(
\bm b-A\bm u^{(k)}
\right).
\label{eq:linear-solvers-jacobi}
\end{equation}

Gauss--Seidel 取
\begin{equation}
M=D+L,
\end{equation}
于是
\begin{equation}
(D+L)\bm u^{(k+1)}
=
\bm b-U\bm u^{(k)}.
\label{eq:linear-solvers-gs}
\end{equation}

对一维 Poisson
\begin{equation}
2u_i-u_{i-1}-u_{i+1}=h^2f_i,
\end{equation}
Jacobi 点更新为
\begin{equation}
u_i^{(k+1)}
=
\frac12
\left(
h^2f_i
+
u_{i-1}^{(k)}
+
u_{i+1}^{(k)}
\right),
\end{equation}
同一轮只读旧状态。若从左到右做 Gauss--Seidel，
\begin{equation}
u_i^{(k+1)}
=
\frac12
\left(
h^2f_i
+
u_{i-1}^{(k+1)}
+
u_{i+1}^{(k)}
\right),
\end{equation}
左邻居已经使用本轮新值。

Jacobi 的一轮点更新天然独立，而 Gauss--Seidel 引入扫描顺序依赖。这一差异后续会同时影响多重网格平滑器和并行实现。

\subsection{收敛阶与收敛因子}

一般迭代序列的经典收敛阶 $p$ 可以由
\begin{equation}
\lim_{k\to\infty}
\frac{
\|\bm e^{(k+1)}\|
}{
\|\bm e^{(k)}\|^p
}
=
C
\label{eq:linear-solvers-convergence-order}
\end{equation}
定义。$p=1$ 称为线性收敛，$p=2$ 称为二次收敛。

但固定线性平稳迭代通常表现为
\begin{equation}
\|\bm e^{(k)}\|
\sim
q^k
\|\bm e^{(0)}\|,
\qquad
0<q<1.
\label{eq:linear-solvers-geometric-convergence}
\end{equation}
此时“线性收敛”本身区分度不大，更重要的是收敛因子 $q$。

若希望误差降到初始值的 $\varepsilon$ 倍，
\begin{equation}
q^k\approx\varepsilon,
\end{equation}
所以
\begin{equation}
k
\approx
\frac{\log\varepsilon}{\log q}.
\label{eq:linear-solvers-iteration-count}
\end{equation}

这里的“迭代收敛阶”不要与 PDE 离散中的
\begin{equation}
\|u-u_h\|=\Oh(h^p)
\end{equation}
混淆：前者研究固定离散系统上 $k\to\infty$ 的代数误差，后者研究 $h\to0$ 时离散解逼近连续解。

\section{克雷洛夫子空间方法}
\label{sec:krylov-methods}

平稳迭代每轮使用固定 $M$。Krylov 方法则利用前几轮算子作用产生的信息，不断扩展搜索空间。

给定初始猜测 $\bm u_0$ 与残差
\begin{equation}
\bm r_0=\bm b-A\bm u_0,
\end{equation}
第 $m$ 阶克雷洛夫子空间（Krylov subspace）定义为
\begin{equation}
\mathcal K_m(A,\bm r_0)
=
\operatorname{span}
\left\{
\bm r_0,
A\bm r_0,
A^2\bm r_0,\ldots,
A^{m-1}\bm r_0
\right\}.
\label{eq:krylov-space}
\end{equation}

Krylov 方法的共同思想是：不直接构造 $A^{-1}$，而是在
\begin{equation}
\bm u_0+\mathcal K_m(A,\bm r_0)
\end{equation}
中选择一个越来越好的近似。不同算法的差别主要在于：如何选取基、如何定义“最好”、利用哪些矩阵结构。

\section{共轭梯度法}
\label{sec:cg}

\subsection{SPD 系统与能量最小化}

假设
\begin{equation}
A=A^T>0.
\end{equation}
求解
\begin{equation}
A\bm u=\bm b
\end{equation}
等价于最小化二次泛函
\begin{equation}
\phi(\bm u)
=
\frac12\bm u^TA\bm u
-
\bm b^T\bm u.
\label{eq:cg-energy-functional}
\end{equation}
因为
\begin{equation}
\nabla\phi(\bm u)=A\bm u-\bm b=-\bm r.
\end{equation}

最速下降法每轮沿当前残差方向搜索，但相邻搜索方向可能重复修正已经处理过的误差。CG 的关键改进是构造彼此 $A$-共轭的方向
\begin{equation}
\bm p_i^T A\bm p_j=0,
\qquad
i\neq j.
\label{eq:cg-conjugacy}
\end{equation}
在这些方向上逐步最小化能量。

\subsection{CG 递推}

从
\begin{equation}
\bm r_0=\bm b-A\bm u_0,
\qquad
\bm p_0=\bm r_0
\end{equation}
开始，第 $k$ 轮计算
\begin{equation}
\alpha_k
=
\frac{\bm r_k^T\bm r_k}
{\bm p_k^TA\bm p_k},
\label{eq:cg-alpha}
\end{equation}
更新
\begin{align}
\bm u_{k+1}
&=
\bm u_k+\alpha_k\bm p_k,
\\
\bm r_{k+1}
&=
\bm r_k-\alpha_kA\bm p_k,
\end{align}
再令
\begin{equation}
\beta_k
=
\frac{
\bm r_{k+1}^T\bm r_{k+1}
}{
\bm r_k^T\bm r_k
},
\label{eq:cg-beta}
\end{equation}
以及
\begin{equation}
\bm p_{k+1}
=
\bm r_{k+1}
+
\beta_k\bm p_k.
\label{eq:cg-direction}
\end{equation}

在精确算术中，CG 最多 $n$ 步可以得到 $n$ 维 SPD 系统的精确解；实际浮点计算中，舍入误差会破坏严格正交/共轭关系，因此工程上仍以残差准则停止。

\begin{algorithm}[htbp]
\caption{共轭梯度法（CG）}
\begin{algorithmic}[1]
\State 给定 $\bm u_0$
\State $\bm r_0\gets\bm b-A\bm u_0$
\State $\bm p_0\gets\bm r_0$
\For{$k=0,1,\ldots$}
  \State $\alpha_k\gets(\bm r_k^T\bm r_k)/(\bm p_k^TA\bm p_k)$
  \State $\bm u_{k+1}\gets\bm u_k+\alpha_k\bm p_k$
  \State $\bm r_{k+1}\gets\bm r_k-\alpha_kA\bm p_k$
  \If{满足停止准则}
    \State \textbf{break}
  \EndIf
  \State $\beta_k\gets(\bm r_{k+1}^T\bm r_{k+1})/(\bm r_k^T\bm r_k)$
  \State $\bm p_{k+1}\gets\bm r_{k+1}+\beta_k\bm p_k$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{条件数与 CG 收敛}

定义能量范数
\begin{equation}
\|\bm e\|_A
=
\sqrt{\bm e^TA\bm e}.
\end{equation}
CG 的经典最坏情形界为
\begin{equation}
\boxed{
\|\bm e_k\|_A
\le
2
\left(
\frac{
\sqrt{\kappa_2(A)}-1
}{
\sqrt{\kappa_2(A)}+1
}
\right)^k
\|\bm e_0\|_A.
}
\label{eq:cg-condition-bound}
\end{equation}
其中
\begin{equation}
\kappa_2(A)
=
\frac{\lambda_{\max}(A)}{\lambda_{\min}(A)}
\end{equation}
对 SPD 矩阵成立。

这条式子第一次把“矩阵条件数”和“迭代次数”直接连接起来。条件数越接近 1，最坏情况下的收敛越快；条件数很大时，CG 可能需要更多迭代。

但式~\eqref{eq:cg-condition-bound} 是上界，不是每个问题的精确迭代数。实际 CG 还受特征值聚集、离群特征值和初始误差方向影响。

\begin{keybox}
\textbf{CG 的适用条件不是可选项：}
\[
\boxed{
A\text{ 必须是 SPD。}
}
\]
若系统非对称或不定，不能仅因为“矩阵很稀疏”就继续使用标准 CG。
\end{keybox}

\section{广义最小残差法}
\label{sec:gmres}

CG 强烈依赖 SPD 结构。对一般非对称系统，需要另一种 Krylov 思路：直接在当前 Krylov 子空间中寻找使残差二范数最小的近似，这就是 GMRES。

\subsection{Arnoldi 过程}

令
\begin{equation}
\beta=\|\bm r_0\|_2,
\qquad
\bm v_1=\frac{\bm r_0}{\beta}.
\end{equation}
Arnoldi 过程逐步构造正交基
\begin{equation}
V_m=
\begin{bmatrix}
\bm v_1&\bm v_2&\cdots&\bm v_m
\end{bmatrix}
\end{equation}
以及上 Hessenberg 矩阵 $\bar H_m$，满足
\begin{equation}
\boxed{
AV_m
=
V_{m+1}\bar H_m.
}
\label{eq:arnoldi-relation}
\end{equation}

这一步把“大型稀疏矩阵上的 Krylov 子空间”压缩成一个很小的 Hessenberg 表示。

\subsection{残差最小化}

GMRES 在
\begin{equation}
\bm u_m
=
\bm u_0+V_m\bm y_m
\end{equation}
中选择 $\bm y_m$。残差为
\begin{align}
\bm r_m
&=
\bm b-A(\bm u_0+V_m\bm y_m)
\\
&=
\beta\bm v_1
-
V_{m+1}\bar H_m\bm y_m
\\
&=
V_{m+1}
\left(
\beta\bm e_1-\bar H_m\bm y_m
\right).
\end{align}
因为 $V_{m+1}$ 的列正交，
\begin{equation}
\boxed{
\bm y_m
=
\arg\min_{\bm y}
\left\|
\beta\bm e_1-\bar H_m\bm y
\right\|_2.
}
\label{eq:gmres-least-squares}
\end{equation}
所以 GMRES 的核心不是一个固定点更新，而是
\[
\boxed{
\text{Arnoldi 构造 Krylov 正交基}
+
\text{小型最小二乘残差最小化}.
}
\]

\subsection{重启与非正规矩阵}

不重启的 GMRES 每轮都需要保存更多 Krylov 基向量，Arnoldi 正交化成本也不断增长。实际软件中常用 GMRES$(m)$：构造至多 $m$ 个基向量后重启，以限制内存和正交化成本。

重启降低了存储成本，但会丢失历史子空间信息，因此可能减慢收敛，甚至出现长期停滞。参数 $m$ 是数值效率与内存成本之间的折中。

还必须注意：对非正规矩阵，GMRES 的行为不能只由特征值位置或谱半径完全解释。特征向量条件、非正规性和多项式逼近性质都会影响收敛。因此不能把平稳迭代中的“$\rho(S)<1$”直接套到 GMRES 上。

\begin{checkpointbox}
\textbf{即时检查}

CG 与 GMRES 都属于 Krylov 方法，但它们利用矩阵结构的方式不同。说明：
\begin{enumerate}
\item 为什么 SPD 条件让 CG 可以使用短递推；
\item 为什么一般 GMRES 需要保存 Arnoldi 基；
\item 为什么 GMRES 的“最小残差”不是指每个分量残差分别最小。
\end{enumerate}
\end{checkpointbox}

\section{预条件}
\label{sec:preconditioning}

\subsection{近似逆的基本思想}

如果存在一个容易应用的算子 $M^{-1}$，满足
\begin{equation}
M^{-1}\approx A^{-1},
\end{equation}
那么
\begin{equation}
M^{-1}A
\approx
I.
\end{equation}
预条件的目标不是“额外做一个求解器”，而是把原系统变换成更适合迭代的方法。

左预条件写成
\begin{equation}
M^{-1}A\bm u
=
M^{-1}\bm b.
\label{eq:preconditioning-left}
\end{equation}
右预条件写成
\begin{equation}
AM^{-1}\bm y
=
\bm b,
\qquad
\bm u=M^{-1}\bm y.
\label{eq:preconditioning-right}
\end{equation}

对 GMRES，左右预条件会改变被最小化的残差含义。右预条件 GMRES 的 Arnoldi 过程作用于 $AM^{-1}$，而原系统残差仍是
\begin{equation}
\bm r=\bm b-A\bm u,
\end{equation}
因此工程上更容易直接监控物理系统的真实残差；左预条件 GMRES 则直接处理预条件残差 $M^{-1}\bm r$。

\subsection{预条件共轭梯度法}

若 $A$ 为 SPD，且预条件矩阵 $M$ 也是 SPD，可以构造预条件共轭梯度法（Preconditioned CG, PCG）。每轮先求
\begin{equation}
\bm z_k=M^{-1}\bm r_k,
\end{equation}
再用 $\bm z_k$ 构造搜索方向。典型递推为
\begin{equation}
\alpha_k
=
\frac{
\bm r_k^T\bm z_k
}{
\bm p_k^TA\bm p_k
},
\end{equation}
以及
\begin{equation}
\beta_k
=
\frac{
\bm r_{k+1}^T\bm z_{k+1}
}{
\bm r_k^T\bm z_k
}.
\end{equation}

从谱角度，更自然的对象是
\begin{equation}
\widehat A
=
M^{-1/2}AM^{-1/2}.
\end{equation}
若 $M^{-1}$ 是好的 $A^{-1}$ 近似，则
\begin{equation}
\kappa_2(\widehat A)
\end{equation}
应显著小于原系统的 $\kappa_2(A)$。

这正是后面“multigrid 作为预条件器”的理论入口：不要求一次 V-cycle 精确解出问题，而是希望它把外层 Krylov 方法看到的系统变得更容易。

\subsection{预条件 GMRES}

一般非对称系统没有 PCG 的 SPD 结构要求，可以使用预条件 GMRES。若 $M^{-1}$ 固定且线性，普通 GMRES 可以在 $M^{-1}A$ 或 $AM^{-1}$ 上建立 Krylov 子空间。

预条件器的效果不能只看一次 $M^{-1}\bm r$ 是否降低残差，还要看整个预条件算子的谱、非正规性、apply 成本以及它与外层 Krylov 方法的相互作用。

\section{柔性 GMRES 与可变预条件}
\label{sec:fgmres}

普通右预条件 GMRES 默认每一步都使用同一个线性 $M^{-1}$。但实际计算中，预条件步骤可能改变：inner solve 的容差不同、multigrid cycle 的次数改变、粗层求解器不固定，或者预条件器本身是非线性的。

若第 $j$ 步使用
\begin{equation}
\bm z_j=M_j^{-1}\bm v_j,
\label{eq:fgmres-variable-preconditioner}
\end{equation}
那么不能再把所有 $\bm z_j$ 统一解释成一个固定 $M^{-1}V_m$。

FGMRES 的关键做法是显式保存
\begin{equation}
Z_m=
\begin{bmatrix}
\bm z_1&\bm z_2&\cdots&\bm z_m
\end{bmatrix},
\end{equation}
Arnoldi 正交化仍围绕
\begin{equation}
A\bm z_j
\end{equation}
展开，最终更新写成
\begin{equation}
\boxed{
\bm u_m
=
\bm u_0+Z_m\bm y_m.
}
\label{eq:fgmres-update}
\end{equation}

这里需要建立的边界非常明确：
\[
\boxed{
\begin{aligned}
\text{固定线性预条件器}
&\Rightarrow
\text{普通预条件 GMRES 通常足够},
\\
\text{逐步变化或非线性预条件器}
&\Rightarrow
\text{考虑 FGMRES}.
\end{aligned}
}
\]

后续\chapref{ch:mg-cycles}会把 $M_j^{-1}$ 具体化为 multigrid V-cycle，并讨论固定 cycle 与可变 cycle 分别适合怎样的外层方法。

\section{方法选择与本章边界}

现在可以形成一个基本选择流程。

若系统规模较小、矩阵固定并且需要重复求解，稀疏直接法可能最简单可靠。

若 $A$ 为 SPD，大规模迭代求解首先考虑 CG；若有 SPD 预条件器，则考虑 PCG。

若 $A$ 一般非对称，GMRES 是基础选择；若内存压力较大，常使用重启 GMRES，但必须检查重启是否损害收敛。

若预条件器会随迭代变化，FGMRES 提供了更自然的外层框架。

Jacobi/Gauss--Seidel 很少因为“它们是最先进的独立求解器”而重要；它们真正进入 multigrid 主线，是因为其局部误差处理具有特殊的频率选择性。\chapref{ch:two-grid}接下来就从这个问题开始：\textbf{为什么一个作为独立求解器越来越慢的 Jacobi，反而可以成为有效的 multigrid 平滑器？}

\begin{keybox}
\textbf{本章完成了两个角色的分离：}
\[
\boxed{
\text{外层求解器}
\neq
\text{预条件器}.
}
\]
CG/GMRES/FGMRES 负责组织搜索空间和迭代历史；预条件器负责把残差变成更有用的修正方向。Multigrid 后面既可以独立迭代，也可以扮演 $M^{-1}$。
\end{keybox}

\section*{习题}

\subsection*{基本求解路线}
\begin{enumerate}[label=\arabic*.]
\item 对以下系统说明更适合优先考虑 LU/Cholesky、CG、GMRES 还是 FGMRES，并给出理由：
  (a) 小型 SPD 系统且矩阵固定；
  (b) 大型 SPD 稀疏系统；
  (c) 大型非对称稀疏系统；
  (d) 非对称系统且预条件器每轮可能变化。
\item 解释稀疏矩阵的“填充”为什么可能让直接法的内存成本远高于原矩阵。
\end{enumerate}

\subsection*{误差、残差与平稳迭代}
\begin{enumerate}[label=\arabic*.]
\item 给定一个 $3\times3$ SPD 矩阵、近似解和右端，计算误差、残差，并验证 $\bm r=A\bm e$。
\item 从式~\eqref{eq:linear-solvers-stationary}推导误差传播矩阵 $S=I-M^{-1}A$。
\item 对一个给定 $S$ 计算谱半径，并判断平稳迭代是否从任意初值收敛。
\item 两种方法的渐近收敛因子分别为 $0.2$ 与 $0.95$。估计把误差降到 $10^{-8}$ 所需迭代数。
\end{enumerate}

\subsection*{CG 与 GMRES}
\begin{enumerate}[label=\arabic*.]
\item 从二次泛函~\eqref{eq:cg-energy-functional}推导 $\nabla\phi=A\bm u-\bm b$，说明为什么 SPD 系统可以解释成凸二次最小化。
\item 对一个 $2\times2$ SPD 系统手算前两轮 CG，并验证搜索方向的 $A$-共轭性。
\item 给定两个 SPD 系统的条件数 $\kappa_2=10$ 与 $10^4$，用式~\eqref{eq:cg-condition-bound}比较理论最坏收敛因子。
\item 从 Arnoldi 关系~\eqref{eq:arnoldi-relation}推导 GMRES 小型最小二乘问题~\eqref{eq:gmres-least-squares}。
\item 解释为什么重启 GMRES 能控制内存，却可能损害收敛。
\end{enumerate}

\subsection*{预条件与柔性方法}
\begin{enumerate}[label=\arabic*.]
\item 比较左预条件与右预条件 GMRES 中“被最小化/监控的残差”有什么差异。
\item 说明 PCG 为什么不仅要求 $A$ 为 SPD，也要求预条件器保持相容的 SPD 结构。
\item 构造一个预条件器每轮改变的例子，解释为什么普通固定右预条件 GMRES 的模型不再准确，以及 FGMRES 为什么需要保存 $Z_m$。
\item 设计一个数值实验，比较无预条件 CG 与 PCG 的迭代数，并同时记录预条件器 apply 的成本，说明“迭代数减少”为什么不等于“总时间一定减少”。
\end{enumerate}
